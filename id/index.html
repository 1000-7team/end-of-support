📄 Пользовательское соглашение

1. Предмет соглашения

1000-7id предоставляет единую систему авторизации на условиях OAuth 2.0 / OpenID Connect.

2. Обработка персональных данных

Сбор и обработка данных осуществляется в соответствии с политикой конфиденциальности.

3. Обязанности разработчиков

Использовать безопасные redirect_uri, не передавать client_secret третьим лицам.

4. Ответственность

1000-7id не несет ответственности при компрометации client_secret по вине разработчика.
